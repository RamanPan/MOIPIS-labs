# План выполнения задания 3-1-2

**Цель.** Расширить проект 3-1-1 и показать, как два процесса согласуют действия по данным друг друга и передают внутренние события по настроенным связям.

**Пример.** Предлагаемый вариант для согласования с преподавателем — подготовка заказа на поставку и проверка заказчика. Шаблоны описываются в JSON, исполнение общее для любых предметных имён.

**Подход.** Добавить профиль `coordination` к существующему Maven-проекту. Новый сеанс хранит запущенные экземпляры и одну очередь сообщений в памяти. Он использует общий каталог, модели шаблонов, правила ролей и вычисление ДНФ. Команды, успешные шаги и попытки доставки записываются в JSONL. Прежний профиль `web` и демонстрация Б.3 служат регрессионными проверками.

**Стек.** Java 21, Maven 3.9+, Jackson, JUnit 5.

Задание и материалы проекта — [условие 3-1-2](../../../task_3-1-2.md), [тесты 3-1-1](../../testing.md), [отчёт 3-1-2](../../report-3-1-2.md).

В рабочей копии реализованы и проверены программные шаги. Согласование варианта с преподавателем и сверка титульного листа остаются перед сдачей. Исходный прогон 3-1-1 в песочнице столкнулся с отказом доступа при очистке временных каталогов JUnit. Итоговый запуск с доступом к временным каталогам подтвердил все 398 проверок, включая 379 прежних.

## Требования, влияющие на реализацию

- Объект из конфигурации существует до `start`. Для одного ID допустим один запуск. Для нового режима шаблон ищется по точному классу. Наследование определений параметров сохраняется.
- Внешний режим 3-1-2 принимает только `start` и `action`. Событие формирует и доставляет сервис. Завершение обработки очереди входит в выполнение команды.
- Допустим один агрегатор как заменяемая стратегия. Для примера выбран `all`. Пустая или отсутствующая связь даёт ложь, а `not` применяется к результату предиката.
- Связи, имена событий, предикаты и переходы задаются конфигурацией. Сеанс начинает работу с готовыми объектами без запущенных процессов. Журнал можно прочитать после перезапуска. Состояние процессов и недоставленные сообщения из него не загружаются.
- Существующие сценарии 3-1-1 должны проходить после расширения. Их путь `createObject` запускает процесс при создании, а `resolveTemplate` допускает шаблон предка. Новый режим использует явный запуск и отдельный точный поиск.
